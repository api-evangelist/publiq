publiq vzw is a Belgian (Flemish) non-profit organisation that stimulates active participation in culture, sport and leisure by making event and activity information accessible. It runs products such as UiTdatabank (the Flemish database of cultural and leisure events), UiTPAS (a leisure discount and savings pass) and museumPASSmusées, and offers the publiq platform through which developers register integrations and receive client credentials for its APIs, including the UiTdatabank Entry API and Search API, the UiTPAS API and the museumPASSmusées API, plus plug-and-play widgets. Documentation, OpenAPI files and Postman collections are published on docs.publiq.be.

**Areas:** Company · Culture · Event · Leisure · Belgium · Non-Profit · Open Data · Loyalty Programs
